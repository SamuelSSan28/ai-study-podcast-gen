# Evaluation

Automated workflow evaluation. All metrics are generated during pipeline execution — no manual spreadsheets.

## Layout

```text
evaluation/
├── cases/           # frozen JSON from repo tests or real plan runs
├── rubrics/         # session-quality.json (weights + rules)
└── results/         # auto-generated by npm run eval:report
    ├── baseline.json
    ├── final.json
    └── report.md
```

Raw run data lives in `artifacts/runs/<run-id>/` (gitignored):

- `trace.json` — stages, timings, OpenAI calls, validations
- `metrics.json` — rubric scores and aggregates

## Commands

```bash
# Pilot (3 cases, skip audio by default)
npm run eval:baseline -- --pilot
npm run eval:final -- --pilot
npm run eval:score
npm run eval:report
npm run eval:export-trajectories

# Full suite
npm run eval:all

# Targeted experiment
npm run eval:experiment -- --toggle=skip-web-research --pilot

# Demo data (no OpenAI) for structure verification
npm run eval:demo
```

## Primary metric

**Average rubric score** on the same frozen cases — baseline (single generic prompt) vs final orchestrated workflow.

See [`results/report.md`](results/report.md) for the latest aggregated comparison.
